# 交易日污染更正报告（2026-07-23）

状态：数据质量修复完成；所有旧回测指标已失效，后续仅使用清洗后重放结果。

## 发现与证据

- 历史面板包含 `2026-06-19` 的 4,579 行全市场记录，但该日端午节休市。
- 修复前面板有 1,102 个日期，基准交易日序列在同一区间只有 1,101 个日期；唯一额外日期为
  `2026-06-19`，没有缺失的合法交易日。
- 旧采集日志把该日判为交易日，并在开盘时段写入全市场快照。文件名和采集成功状态因此把非交易日
  错当成了有效交易日。
- 官方依据：[上交所休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260611_10821419.shtml)、
  [深交所休市安排](https://www.szse.cn/disclosure/notice/general/t20260611_620979.html)。

| 面板日期数 | 1,102 | 1,101 |

## 对模型结果的影响

旧冠军总收益 27.71%、年化 7.55%、Sharpe-like 0.4605 均已失效。用完全相同的生产规则在干净面板
重放后，总收益为 25.86%，年化 7.09%，最大回撤 -28.26%，Sharpe-like 0.4381。移除非法日期还会
改变五日调仓和滚动训练相位，因此不能只从旧净值中删除单日收益。

## 永久控制

- 面板更新、训练、容量测试和每日风险挑战者都已接入交易日集合硬校验。
- 面板日期必须与基准交易日序列在首末日期范围内完全一致，否则立即停止。
- 非交易日快照只允许隔离，不允许自动修补；发现历史污染后必须按冻结配置重放全部受影响结论。
- 本次失效的关键旧产物已保存在 `outputs/data_quality_quarantine_20260723`，不得再作为策略证据。

本报告仅用于研究和数据审计，不构成交易建议。
