# 市场宽度与风险目标错配前瞻观察器

## 目的

清洗交易日历后的归因显示，负收益年份经常伴随可用股票中站上 MA60 的比例偏低，
而正式模型的 510300 市场风险目标仍可能保持在 60% 或以上。该现象目前只是待验证
假设，不能据此回改历史参数或改变正式模型。

## 冻结口径

- 登记日：2026-07-23
- 前瞻观察起点：2026-07-23
- 弱宽度标签：`breadth_above_ma60 < 0.50`
- 高风险目标标签：`model_market_exposure_target >= 0.60`
- 诊断复核门槛：60 个已成熟信号收益
- 收益口径：`trade_audit.signal_date -> realize_date` 对应的净收益
- 效果边界：不改选股、不改仓位、不改订单、不自动晋级

阈值只负责形成可重复的诊断分组，不是生产减仓阈值。实际总仓位和 510300 风险目标
必须同时展示，避免把“目标较高”误读为“当前已经高仓运行”。

## 前瞻完整性

观察器每次只登记当次输入中实际看到的最新交易日。已经登记的宽度、横截面收益中位数、
风险目标和登记时间不可被后续历史数据修订覆盖；待对应信号出现在 `trade_audit.csv` 后，
才补充实现日与净收益。禁止用 `equity_curve.csv` 的同日行或下一行代替该映射，因为净值日期
是实现日，市场诊断日期是信号日。

## 当前状态

截至 2026-07-22 的数据只作为登记前背景快照：MA60 宽度为 10.40%，横截面 20 日收益
中位数为 -11.25%，510300 风险目标为 60%，实际总仓位为 0%。前瞻有效观察为 0，
成熟结果为 0/60，因此不能形成效果结论。
